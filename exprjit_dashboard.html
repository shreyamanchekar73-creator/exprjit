Synopsis objectives

Mapped against the original proposal, including where the implementation diverged.
Fast lexer for the query language

Proposed with Logos; implemented as a hand-rolled tokenizer instead, to remove a dependency-version risk in a project already relying on Cranelift and Arrow for native codegen. Fully unit-tested.

implemented differently
Parser building a well-formed AST

Proposed with Chumsky; implemented as a hand-rolled recursive-descent parser instead, for the same dependency-risk reason. Handles full operator precedence, parentheses, and unary negation of predicates.

implemented differently
AST → native machine code via Cranelift

Every query compiles to a real unsafe extern "C" fn at runtime, not bytecode or a closure tree.

done
Direct evaluation over Arrow's columnar buffers

The compiled function reads raw pointers into each column's contiguous buffer — no intermediate row objects, no copies.

done
Query-shape compilation cache

Structurally identical expressions reuse a previously compiled function instead of recompiling — keyed on AST shape plus schema layout, not the raw query string.
